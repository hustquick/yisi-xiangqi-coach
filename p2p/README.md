# 中国象棋网络对战（联调版）

当前接入 `windowsHTML` 和 `html` 两个网页客户端。安卓 / iOS 原生客户端尚未接入，不能把旧 APK 当作网络对战版。

所有账号与好友操作都在“网络对战”模块内完成。登录只输入一次密码；切换注册后显示确认密码，两次不一致不提交。上线后可按完整账号（不区分大小写）搜索、添加或移除好友；好友列表持久化到账号数据库。在线、离线和对局中状态随在线连接推送更新，离线或忙碌好友不能被邀请。添加是单方收藏，不自动把对方加入你的好友关系，也不表示双方已相互同意好友申请。

模块内直接显示账号和账户状态下拉框（在线 / 隐身 / 退出），只保留一个“好友列表”展开入口，不显示重复的账户信息、恢复在线或退出登录按钮。状态选择保存到服务器；隐身账号在好友列表与搜索结果中均显示离线，不公开是否隐身或忙碌。隐身玩家仍能主动邀请在线玩家（发起邀请即向对手暴露账号）；已有对局不受状态切换影响。好友列表支持查看好友账号、当前公开状态和邀请可用性。对局中需先退出对局，才能退出账号。

账号使用服务端 SQLite 保存，密码使用独立随机盐的 scrypt 哈希；密码只要求非空、最多 128 个字符，无复杂度要求，允许一个字符的短密码（更容易被猜中，不要复用重要账号密码）。登录令牌仅在客户端内存保存，12 小时有效。当前需要该账号服务在线，不是完全去中心化账号。实时走棋仍走点对点；只有玩家主动保存的个人棋谱会上传账号服务。

## 个人云端棋谱

公网网页的“棋谱与存档”提供“保存到云端”“我的云端棋谱”。登录后，可保存完整初始局面、走法、当前复盘位置和分析评分；从个人列表载入或下载 JSON，再通过本机导入功能载回。服务端每次查询均使用登录令牌的账号过滤，不接受客户端指定所有者。每账号最多 200 份，每份最多 24 KB，不覆盖旧存档；当前未提供删除或重命名。云存档不等于备份承诺，重要棋谱请同时下载。对局中只能保存或下载，不允许载入改变棋盘。其他网页客户端和原生端尚未接入云存档界面。

邀请方执红，接受方执黑，从标准初始局面开始。走棋使用有序 WebRTC DataChannel，携带对局 ID、半回合序号和落子前局面；双方独立检验规则和回合，收到非法消息或确认超时即锁定对局。禁止联网时单方悔棋、重开、摆盘和载入。断线重连会核对双方现有局面，局面不一致不自动覆盖对手棋盘；关闭或刷新网页后的棋局恢复尚未实现。退出不是竞技认输结算，没有排名或防引擎作弊保证。

## 服务运行

需要 Node 22.13+（SQLite 内置支持）：

```sh
cd p2p
npm install
npm test
P2P_ORIGINS=http://localhost:8080 npm start
```

网页构建前先在 `p2p` 和对应客户端目录运行 `npm install`。`windowsHTML` 执行 `npm run build`；联网时以 HTTP 本机服务或 HTTPS 托管网页，不能只双击文件保证联网功能。

## 网络恢复与邀请

在线信令断开后自动按 1–30 秒退避重试；退出账号或账号被其他设备替换时停止重试。恢复后核对服务端是否仍保留当前对局；已结束的对局解除锁定，不重开或覆盖棋盘。邀请有效期 60 秒，清理通知最多延迟一个维护周期（15 秒）；禁止同一对手的重复待处理邀请，重新上线会收到尚未过期的邀请。

部署配置参考 [coturn 官方配置说明](https://github.com/coturn/coturn/blob/master/examples/etc/turnserver.conf)。公网强制 TURN 测试通过后，应继续进行跨网络真机和长期流量验收。

## 验证范围

`npm test` 检查注册、密码校验、来源限制、令牌替换和未授权对局操作。`npm run test:browser` 使用两个独立浏览器上下文连接真实云端服务，经真实 WebRTC 完成邀请、双方落子、禁止单方重开、重连和退出；需先开启 SSH 隧道和网页本机服务，`CHROME_PATH` 可指定 Chrome 路径。

设置 `P2P_TEST_PAGE=https://141.148.168.171 P2P_TEST_RELAY=1` 可验证真实中继。尚需跨网络真机、移动端后台恢复、长期流量和异常消息压力测试。刷新后的棋局恢复尚未实现，不声称竞技平台级交付。
