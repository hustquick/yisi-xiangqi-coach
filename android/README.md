# 弈思象棋教练 Android

这是原生 Android 版本，不是 WebView。界面使用 Android 原生 View/Canvas；官方 Pikafish C++ 通过 JNI 编译进 APK，`pikafish.nnue` 随应用打包，因此合法着法、候选分析和评分均可完全离线运行。

## 功能

- 原生中国象棋棋盘，含黑方 `1–9`、红方 `九–一` 路数标记
- 一键红黑倒置，棋子、合法落点、候选箭头、河界和路数同步切换到对方视角，不改变行棋方或引擎局面
- 思考深度可选 `8 / 10 / 12 / 14 / 16`，默认 12；对局中切换会停止旧计算并立即按新深度重算
- 先快速发布合法着法，深度分析期间仍可选子和行棋；落子后自动停止旧分析并计算对方应着
- 点击棋子显示合法落点，绿色表示该棋子的皮卡鱼首选，蓝色表示其他合法落点
- 圆形“优”按钮控制全局候选箭头；`1–4` 表示皮卡鱼前四名不同候选，即使只有一个候选也显示 `1`
- 空目标箭头指向交叉点；有棋子时停在棋子圆边但仍朝向交叉点中心；编号圆圈真实截断箭身
- 全局最佳、选中棋子的候选、当前评分和走后评分与局势图统一采用红方视角（正数红优、负数黑优），并提供包含评分变化、首选替代和随后 4 个半回合主变化的动态着法评价
- 局势图按每个半回合记录皮卡鱼评分：零线上方为红优，下方为黑优；点击任意点可回到该局面并从那里创建新分支。落子过快导致的缺失评分会在当前分析结束后由后台逐步补算，期间保持空缺而不是伪造 0 分
- 单击候选弹出中文后续主变化，双击直接落子；并支持悔棋、重开和走法记录；双方各走一步计 1 回合
- App 图标使用“象”；运行时不需要网络

## 兼容性

- Android 8.0（API 26）及以上
- 当前 APK 包含 `arm64-v8a`，适用于绝大多数近年 Android 手机

## 构建与安装

```bash
# 在仓库根目录执行
android/gradlew -p android assembleDebug

# USB 调试已连接时安装
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

也可以在 Android Studio 中打开 `android` 并运行 `app`。生成的调试 APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。
